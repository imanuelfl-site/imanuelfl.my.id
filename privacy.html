Privacy Policy

Postiz Imanuel · Last updated October 2026

Postiz Imanuel (postiz.imanuelfl.my.id) is a private, self-hosted scheduling tool operated by Imanuel Friendly Lawalata.

Information we collect

When a TikTok account is connected through TikTok Login Kit, we receive basic profile information (open ID, display name, avatar) and access tokens. We also store the videos, captions and schedules the user uploads.

How we use it

This information is used only to publish content to the connected account at the time the user chooses. It is not used for advertising.

Sharing

We do not sell, rent or share data with third parties. Data is sent only to the platform the user publishes to.

Storage and security

Data is stored on our own self-hosted server, and access is restricted to the operator.

Deletion

Users can revoke access at any time in TikTok’s settings (Security and permissions → Apps), or email us to have all stored data and tokens deleted.
